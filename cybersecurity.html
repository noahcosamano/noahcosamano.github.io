AmanoWatch Intrusion Detection System

An open-source Intrusion Detection System built for network enthusiasts, penetration testers, and security professionals. It provides real-time detection of threats including port scans, brute force attemots, ARP scans, ICMP ping sweeps, ARP spoofing, DNS tunneling, ICMP tunneling, and honeyport connections — alongside a lightweight interface to filter and view live and historical network traffic.
